['Insync](https://www.insynchq.com/) - aplicação de sincronização multi-nuvem com interface TUI (Terminal User Interface) desenvolvida em Go.\n\n![GitHub](https://img.shields.io/github/license/thiagohmm/insync-clone)\n![GitHub go.mod Go version](https://img.shields.io/github/go-mod/go-version/thiagohmm/insync-clone)\n\n## 📝 Descrição\n\nO Insync Clone é uma aplicação que permite sincronizar arquivos entre seu computador e serviços de armazenamento em nuvem como Google Drive e OneDrive. Ele oferece dois modos de sincronização:\n\n1. **Base Sync**: Sincroniza arquivos da nuvem para o local (download), mas não espelha deleções\n2. **Full Sync**: Sincronização bidirecional, espelhando todas as operações entre local e nuvem\n\nA aplicação possui uma interface TUI (Terminal User Interface) construída com [Bubble Tea](https://github.com/charmbracelet/bubbletea) que permite navegar pelas pastas da nuvem e configurar sincronizações diretamente do terminal.\n\n## 🚀 Funcionalidades\n\n- Autenticação OAuth2 com Google Drive e OneDrive\n- Navegação em pastas da nuvem via interface TUI\n- Configuração de sincronização por pastas\n- Dois modos de sincronização (Base e Full)\n- Monitoramento em tempo real do status de sincronização\n- Watcher de sistema de arquivos para detecção de mudanças locais\n- Polling periódico para detecção de mudanças na nuvem\n\n## 🏗️ Arquitetura\n\nO projeto segue uma arquitetura limpa (clean architecture) dividida em:\n\n`\ncmd/\n├── cli/        # Interface TUI para interação com o usuário\n├── server/     # Servidor gRPC que gerencia as operações de sincronização\ninternal/\n├── adapters/   # Adaptadores para banco de dados e sistema de arquivos\n├── domain/     # Entidades e interfaces principais\n├── infrastructure/ # Implementações de gRPC e workers\n├── usecases/   # Casos de uso da aplicação\napi/\n├── proto/      # Definições de API gRPC\n`\n\n## 🛠️ Tecnologias\n\n- [Go](https://golang.org/)\n- [gRPC](https://grpc.io/)\n- [SQLite](https://www.sqlite.org/)\n- [Bubble Tea](https://github.com/charmbracelet/bubbletea) para TUI\n- OAuth2 para autenticação\n\n## 📦 Instalação\n\n### Pré-requisitos\n\n- Go 1.26+\n- SQLite3\n\n### Passos\n\n1. Clone o repositório:\n`bash\ngit clone https://github.com/thiagohmm/insync-clone.git\ncd insync-clone\n`\n\n2. Instale as dependências:\n`bash\ngo mod tidy\n`\n\n3. Compile o projeto:\n`bash\n# Compile o servidor\ngo build -o insync-server ./cmd/server\n\n# Compile o cliente CLI\ngo build -o insync-cli ./cmd/cli\n`\n\n## ▶️ Uso\n\n1. Inicie o servidor (daemon):\n`bash\n./insync-server\n`\n\n2. Em outro terminal, execute o cliente CLI:\n`bash\n./insync-cli\n`\n\n3. Siga as instruções na interface TUI:\n - Escolha um provedor (Google Drive ou OneDrive)\n - Autentique-se via OAuth2 (será aberto um navegador)\n - Navegue pelas pastas da nuvem\n - Escolha uma pasta e configure a sincronização (teclas `b` para base-sync ou `s` para full-sync)\n\n## 🧪 Estrutura do banco de dados\n\nO projeto utiliza SQLite para persistir dados de contas, configurações de sincronização e metadados de arquivos. O arquivo do banco é criado automaticamente como `insync.db`.\n\n## 📄 Licença\n\nEste projeto está licenciado sob a licença MIT - veja o arquivo [LICENSE](LICENSE) para detalhes.\n\n## 🤝 Contribuições\n\nContribuições são bem-vindas!
